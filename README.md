# ShroomTalk 🍄

An AI-powered financial advisory assistant for rural mushroom farmers.

ShroomTalk aims to help rural mushroom entrepreneurs understand financial planning, government schemes, and cultivation-related costs.

## 🎯 Key Features

- AI Chat Assistant using Retrieval-Augmented Generation (RAG)
- Information about government schemes
- Loan EMI estimation
- Margin money calculation
- Mushroom cultivation cost analysis
- Business viability estimation

## 🛠️ Technologies

- Python
- Artificial Intelligence (AI)
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)

## 🎯 Objective

To make financial information and business guidance more accessible to rural mushroom farmers and small entrepreneurs.
